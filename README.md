# 💻 8085 Assembly Tutorial Collection

A collection of basic programs for the **Intel 8085 microprocessor**, designed to be run using the [8085 Simulator](https://github.com/8085simulator/8085simulator).

## 🎯 Purpose

This project serves as educational material and practice for understanding the fundamentals of **8085 Assembly programming**, including basic operations such as addition, subtraction, data storage, and data exchange between registers or memory.

## 📁 Folder Structure

```

programs/
├── exchange-data.asm         ; Exchanges the contents of two memory locations
├── exchange-data-2.asm       ; Alternate version of data exchange
├── store-data-8bit.asm       ; Stores 8-bit data into memory
├── store-data-8bit-2.asm     ; Alternate version of data storage
├── sum-8bit.asm              ; Adds two 8-bit numbers
├── sum-16bit.asm             ; Adds two 16-bit numbers
├── subtract-8bit.asm         ; Subtracts two 8-bit numbers
└── subtract-16bit.asm        ; Subtracts two 16-bit numbers

```

## ▶️ How to Run

1. **Download and launch the 8085 Simulator:**
   - Simulator repository: [8085simulator/8085simulator](https://github.com/8085simulator/8085simulator)
   - Follow the installation instructions based on your operating system

2. **Open the simulator**, then choose:
   - `File > Open` and select any `.asm` file from the `programs/` folder

3. **Run the program**:
   - Use `Assemble`, `Load`, then press `Run` or use `Single Step` to observe execution step-by-step

## 🧪 Program List

| Program Name           | Description                                 |
|------------------------|---------------------------------------------|
| `exchange-data.asm`    | Exchanges data between two memory locations |
| `store-data-8bit.asm`  | Stores an 8-bit value into memory           |
| `sum-8bit.asm`         | Adds two 8-bit values                       |
| `sum-16bit.asm`        | Adds two 16-bit values                      |
| `subtract-8bit.asm`    | Subtracts one 8-bit value from another      |
| `subtract-16bit.asm`   | Subtracts one 16-bit value from another     |
